    文档台 v1.2.0

    本地优先的单据结构化工作台。拖入发票 / 单据，抽取字段与明细，核对后一键导出。数据全程不出本机。

    使用流程

    1. 导入 — 拖入文件、点击选择、导入文件夹，或直接 Ctrl+V 粘贴单据文字
    2. 核对 — 低置信度字段黄色标注，点单元格可内联修正，切「原文对照」逐页追溯出处
    3. 复核 — 修正任意值会自动取消复核并写入留痕；确认无误点「标记复核」，异常项可导出清单
    4. 交付 — 设置案卷后导出 Excel / 核对报告 / 记账凭证 / 交付包 ZIP（含底稿、CSV、报告、凭证、原文）；「客户模板导出」可按客户 ERP 列头自定义映射；≥2 份可汇总
    5. 经营 — 顶栏「客户与案卷」管理客户档案、多案卷、计费规则与工作量，查看经营 KPI，并导出服务对账单（CSV / Excel）
    6. 归档 — 结果自动落盘到本机 data/workspace.db，可创建时间点快照并一键回滚；也支持工作区 JSON 备份换机恢复

    支持格式

    PDF（逐页）· Word · Excel · TXT · CSV · JSON · HTML · Markdown · 图片与扫描件。扫描 PDF 和图片自动使用本地 OCR（Windows 内置引擎，零安装零费用；每页约 3–5 秒），识别后请用原文对照人工核对。

    数据与隐私

    全部解析与 OCR 在本机完成，无第三方 API、无云端上传。结果同时保存在浏览器与本机 data/workspace.db，可在案卷设置中创建快照、回滚或导出 JSON 备份。

    关于品牌

    「折角单据 → 长短数据行 → 复核勾」：把散乱单据变成可核对的结构化数据。原创矢量标志，无外部字体与图片依赖，可随交付物商用。
